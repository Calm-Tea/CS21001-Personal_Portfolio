My Projects

A few of my projects I enjoyed making

Chess AI

As part of our AI module we had a chance to make both a search based AI and to train a ML model. I focused on the search based AI. I implemented a heuristc evaluation mostly based on piece positional values. A minimax algorithm to predict the best move by taking into account your oppenents next couple of moves. It was a really interesting subject that I'm hoping to pursue in my own time. For my part of this project I used python and made extensive use of the chess library. I had a problem at first where the AI would make essentially random moves, that was fixed using the positional value tables.

Project Nova

This was an assignment where we had to develop a Battleship like game. while not the most demanding or difficult project it was nice to make something interactive. For this project I used Java with Java Swing for the GUI. I encountered a lot of problems while implementing the GUI especially around threads, which I wasn't initially planning to do as it was not strictly neccessary. My code got a bit to complicated because of the addition of GUI but I fixed with a bit of moving code around the classes.

A calendar app
